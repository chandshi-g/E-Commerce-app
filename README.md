# E-Commerce Application

A full-stack E-Commerce application built using:

- Spring Boot
- MySQL
- Vue.js
- Docker
- Docker Compose

---

## Requirements

Install:

- Docker Desktop

---

## Run the project

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/E-Commerce-Application.git
```

Move inside

```bash
cd E-Commerce-Application
```

Run

```bash
docker compose up
```

Open

Frontend

```
http://localhost:3030
```

Backend

```
http://localhost:8080
```

MySQL

```
localhost:3307
```

Stop

```bash
docker compose down
```
